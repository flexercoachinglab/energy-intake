# FLEXER 摂取カロリー設定ツール

FLEXERオリジナルの活動係数（辛口）に基づき、体重維持・減量推奨の摂取カロリーを
レンジで算出する個人用ツール。Next.js 14 (App Router)。

- 活動係数: 職業(出発点) ± 主観的疲労度 ± 歩数 + 運動習慣
- 減量目標: 月-0.5〜-3kg スライダー
- 基礎代謝割り込み時は非推奨メッセージを表示
- PFC目安（P=体重×1.3〜1.4g / F=総kcalの20% / 残りC）と指導文を出力

## 開発
npm install
npm run dev
